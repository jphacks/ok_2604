## 製品概要
### 将来の夢に向けて挑戦したとしても先が長く，何をすればいいかわからなくなってしまう。
### 既存の勉強サポートアプリだけでは今日の勉強の時間のみしか測れなかったところを，測ることのできない活動（ハッカソンに参加，インターシップに参加，参考書を買いに行った，etc）の記録，将来やりたいことから細分化し身近なタスクへの置き換えがで（具体的な製品の説明）
### 特長
#### 1. 将来とゆう先の見えないマラソンを，ゲームの攻略とゆう身近で楽しいものにする。
#### 2. 勉強時間ではなく，その日の行動（ハッカソンの参加，インターンシップ，etc）も成果にすることができる
#### 3. 将来つきたい職業から必要な実績や，今取り組めるタスクを教えてくれる。
#### 4. フレンド機能で，同じ夢を目指している人はどのような行動（とった資，勉強している科目），友人の頑張りを見ることが出来，モチベーションを持ち続けたり，同志の行動を参考にすることができる。 

### 解決出来ること
*勉強時間では測れないものは意味がないところ
*長期目標を達成するために必要なことが分からないとこ
*周りの人はどんな取り組みをしているのかわからない
### 今後の展望
*長期目標のためには「続けること」が重要であり，現在は毎日続けもらうためにデイリークエストや，1日の活動を報告すると，経験値をもらいレベル上げをするが，レベル上げでできることが少ないため，レベル上げに意味を持たせる

#### ハッカソンで開発した独自機能・技術
* 目標を「魔王から小さな怪物へ」分割できる目標ツリー
最終目標を魔王とし、AI が具体的な小目標(資格・教科書・作品・経験)に分割。納得するまで何段でも分割でき、層が深いほど小さな怪物(魔王 → ドラゴン → ゴーレム → ゴブリン → スライム)になる。
* 失敗や挫折を「成長」に変える AI 分析
* 日々の出来事から、自由な名前のスキル(例:「羞恥耐性」「勇気」)、今日の収穫、未来へのリターン、経験値を AI が返す。
* コードだけで描いたドット絵アニメーション
* 画像素材を一切使わず、勇者・怪物 5 種・装備 18 種・魔王撃破の演出を Canvas で描画。レベルで装備が変わり、画面最上部で勇者と怪物が戦い続ける。
* 認証・クラウドセーブ・ともだち機能を持つバックエンド
* Cloudflare Worker と KV で自作。パスワードは PBKDF2 でハッシュ化、ログイン失敗のロック、AI の利用回数制限、ともだち申請→承認、ともだちの目標・勉強中の状態・撃破した怪物の閲覧。
べんきょうタイマー、デイリーミッション(連続日数つき)、履歴と撃破の取り消し
