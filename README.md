* 「ゲストで試す」は、AI を使えません。画面の雰囲気を見るだけの用途です。

## 製品概要
将来の夢に向けて挑戦したとしても先が長く、何をすればいいかわからなくなってしまう。そんなときに、AI が目標の達成に必要なことを分析し、自分が今何をすればいいのかを具体的に教えてくれます。分けたステップは、納得できるまで何度でもさらに細かく分けられ、最後は「今日できること」まで落とし込めます。

既存の勉強サポートアプリは、今日の勉強時間しか測れませんでした。このアプリは、時間では測れない活動(ハッカソンへの参加、インターンシップへの参加、参考書を買いに行った、など)も記録して成果にし、将来やりたいことを細かく分けて、身近なタスクに置き換えます。

## 特長
1. 将来という先の見えないマラソンを、ゲームの攻略という身近で楽しいものにする。
2. 勉強時間だけでなく、その日の行動(ハッカソンへの参加、インターンシップ、など)も成果にできる。
3. 将来就きたい職業から、必要な実績や、今取り組めるタスクを教えてくれる。
4. ともだち機能で、友人がどんな目標に向かって、どんな行動(取った資格、勉強している科目)をしているかを見られる。友人の頑張りが励みになり、行動の参考にもなる。

## 解決できること
* 勉強時間では測れない活動が、評価されない。
* 長期目標を達成するために、何が必要かわからない。
* 周りの人がどんな取り組みをしているのか、わからない。

## 今後の展望
長期目標には「続けること」が重要です。現在は、毎日続けてもらうために、デイリーミッションと、1日の活動を報告すると経験値をもらってレベルが上がる仕組みがあります。ただ、レベルを上げてできることがまだ少ないため、レベルアップに意味を持たせる機能を増やしたいと考えています。

## 注力したこと(こだわり)
* 大きな目標を教えてくれることでAIがそれを読み取り具体的な小さな目標を作成してくれるとこ
* 成果の見えない努力を記録し経験値のように見える形にしてくれる。またそれを記録してくれる。


## 開発技術
### 活用した技術
**API・データ**
* Google Gemini API(モデル:gemini-3.5-flash-lite)── 毎日の記録の分析、目標の分割、学習内容からの経験値の算出
* Cloudflare KV ── ユーザーアカウント・セーブデータ・ともだち情報の保存
* Google Fonts(DotGothic16 / Noto Sans JP)── ドット絵風の表示

**フレームワーク・ライブラリ・モジュール**
* 外部のフレームワーク・ライブラリは使用していません(素の HTML / CSS / JavaScript)
* Cloudflare Workers(バックエンド)、Cloudflare Pages(ホスティング)、Wrangler(デプロイ用 CLI)

**デバイス**
* PC・スマートフォンのブラウザ(使った機種を書く)

### 独自技術(ハッカソンで開発した機能)
* **目標を「魔王から小さな怪物へ」分割できる目標ツリー**
  最終目標を魔王とし、AI が具体的な小目標(資格・教科書・作品・経験)に分割。納得するまで何段でも分割でき、層が深いほど小さな怪物(魔王 → ドラゴン → ゴーレム → ゴブリン → スライム)になる。
* **失敗や挫折を「成長」に変える AI 分析**
  日々の出来事から、自由な名前のスキル(例:「羞恥耐性」「勇気」)、今日の収穫、未来へのリターン、経験値を AI が返す。
* **コードだけで描いたドット絵アニメーション**
  画像素材を一切使わず、勇者・怪物 13 種・装備 18 種・魔王撃破の演出を Canvas で描画。
* **認証・クラウドセーブ・ともだち機能を持つバックエンド**
  Cloudflare Worker と KV で自作。パスワードは PBKDF2 でハッシュ化、ログイン失敗のロック、AI の利用回数制限、ともだち申請→承認。
* **鍛錬記録、デイリーミッション(連続日数つき)、履歴と撃破の取り消し**
